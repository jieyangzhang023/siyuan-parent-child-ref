# 父子文档引用 / Parent-Child Doc References

思源笔记插件：在父级文档末尾的表格中自动引用所有子文档，并检查、清理不合法的引用。所有操作都在一个弹窗里完成，带进度条、统计和结果列表。

## 功能

- **一键引用**：扫描工作空间内所有有子文档（或已有引用表格）的文档，**只处理存在缺失或不合法引用的文档**。
  - 补全缺失的子文档引用，清除不合法的行。
  - 没有引用表格的文档，会在末尾新建一个表格，每个直接子文档一行，内容为该子文档的块引用。
  - 没有问题的文档不会被改动。
  - 执行前会先确认。
- **一键检查**：只读，不修改文档。检查所有引用表格中的每条块引用，以下情况视为不合法：
  - 目标块不存在；
  - 目标不再是该文档的直接子文档；
  - 重复引用。

  同时列出尚未被引用的子文档。检查完成后可在弹窗底部：
  - **一键清除不合法引用**：删除所有不合法的行，完成后自动重新检查；
  - **补全未引用**：为漏掉子文档的文档补上引用。

## 入口

顶栏链接图标、文档标题图标菜单、文档树右键菜单、命令面板（可在「设置 → 快捷键 → 插件」中绑定快捷键）。

## 引用表格的识别

满足以下任一条件的表格会被当作引用表格（每个文档取一个）：

- 带有块属性 `custom-child-ref-table`（插件创建，或首次修改已有表格时自动补上）；
- 表头为单列「子文档」的表格（兼容已有的手写表格）。

其他表格不会被改动。

## 安装

将本目录复制到 `<工作空间>/data/plugins/siyuan-parent-child-ref/`，在「设置 → 集市 → 已下载 → 插件」中启用。需要思源 3.0.0 及以上。

## 注意

- 「一键引用」「清除」会改写文档，建议先用「一键检查」查看结果；误操作可在思源「数据历史」中回退。
- 以段落等非表格形式写的父子引用不在处理范围内。
