# 父子文档引用 / Parent-Child Doc References

- **一键引用**：扫描工作空间内所有有子文档（或已有引用表格）的文档，仅处理存在缺失或不合法引用的文档：补全缺失的子文档引用、清除不合法的行；没有表格的文档会在末尾新建；无问题的文档不会被改动。
- **一键检查**：扫描工作空间内所有带引用表格的文档，检查表格中的每条块引用——目标块不存在、目标不再是当前文档的直接子文档、重复引用均视为不合法；支持一键清除，并提示尚未引用的子文档。

入口：顶栏图标菜单、文档标题图标菜单、文档树右键菜单、命令面板/快捷键（设置 → 快捷键 → 插件）。

表格通过块属性 `custom-child-ref-table` 识别，手动新建的表格不会被改动。

安装：将本目录复制到 `<工作空间>/data/plugins/siyuan-parent-child-ref/`，在「设置 → 集市 → 已下载 → 插件」中启用。
